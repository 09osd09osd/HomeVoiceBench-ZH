# 数据构成与生成

本版共1,000题：工具30场景×20题，聊天20场景×20题。每个场景分4个内容家族，每个家族分别有1、2、3、4、5轮版本，因此正常路径共有3,000轮用户语音，1至5轮各200题。最多5轮包含澄清；工具内部往返不算用户轮。

easy/medium/hard是预设标签：1至2轮easy、3轮medium、4至5轮hard，不是根据本次模型得分反推的经验难度。

## 一道题怎样产生

1. **先定义任务与答案。** 代码定义初始家庭、权限、故障、每轮需求和参考工具动作；在真实沙箱执行参考动作，保存响应与状态检查点。聊天题先定义话题、约束和参考表达要求。
2. **再生成自然说法。** DeepSeek-v4.1-flash每批5题、最多12个并发请求，将蓝图写成口语。它不能改写环境真值、工具协议或预算。保存请求ID、提示词与原始响应。
3. **机器检查与第二次审读。** 做JSON Schema、数量、分布、预算、参考轨迹、状态检查和重复检查；再由同一DeepSeek模型通过独立请求审读文字。失败批次保留原因后修复。该过程不是独立模型交叉验证，也不是人工审题。
4. **统一可朗读文字。** 对数字、百分比、时间、日期和单位做确定性转化，保留原稿与实际合成文本。工具参数不做中文文字替换。
5. **并发合成。** qwen-audio-3.1-tts-next生成24kHz单声道WAV，最多16并发，按内容和声音配置缓存。4种成年普通话声音提示分配到题目，同题保持声音一致；没有真人声纹身份认证或儿童录音。
6. **听音质检。** Qwen3.8-Omni-Flash温度0实际听输入，检查是否符合稿件。忽略他/她/它这种无法从声音区分的同音字，以及等价数字格式。v3明确将录音当作待检查数据，避免跟着游戏指令回答。未通过的片段重新合成，保留历史。
7. **冻结。** 每道题与实际引用WAV记录SHA256。三条系统使用同一份冻结输入，各题重置独立沙箱。

实际引用去重输入语音为1,648段、7,193.28秒（约2小时）。数量小于3,000，因为家族内的短版和长版共享前缀；引用集合也包含澄清/回退语音。冻结表示机器校验和哈希固定，**不表示经过人工审核**。

## 对话怎样继续

每个系统保留自己的真实历史，不用参考答案替换上一轮。默认沿冻结节点继续；固定的可见文本规则识别澄清问题后选择预写分支。工具题最多使用一次通用回退语音，仍占用户轮次。没有实时大模型自由扮演用户。

## 划分与适用范围

本版全部标记为test，独立冒烟试验在1000题之外。同一家族的题不是独立样本，置信区间按场景聚类。两对完全相同的台词 `T06_011 / T29_011`、`T25_016 / T28_016` 使用不同环境或故障，保留为对照，不能冒充自然独立数据。

本版测干净合成普通话、短多轮和家庭工具执行，不支持远场噪声、方言、打断、回声、多人同时说话或长期记忆的结论。数字转化是三条系统共有的部署组件，未做关闭转化的消融实验。完整场景目录见 [SCENARIOS.md](SCENARIOS.md)。
