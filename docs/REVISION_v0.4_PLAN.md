# v0.4 重构计划（已授权）

保留 v0.3 数据、语音、轨迹、成绩和发布版本。新版源码位于 `versions/v0.4`，开发集和正式集独立存放。

- 正式集：工具30场景、聊天20场景，每场景20题，共1000题。
- 每场景：2组×4题成组题（40%），12题独立题（60%）；基础12题、标准6题、挑战2题。
- 开发集：独立100题，工具60/聊天40；40题属于10个完整题组，60题独立；基础60/标准30/挑战10。与正式集按题组隔离。
- 10个常用工具，2个异步扩展工具；合并设备查询、提供可信公共上下文、逐次检查授权；每个环境三系统工具集合一致。
- 主要成绩依据任务必须项、客观状态、授权与真实语音反馈；六维体验分单独报告。允许等价表达和合法不同工具路径。
- 三系统的内容/工具决策均用greedy。Qwen使用temperature=0、presence/frequency penalty=0、repetition penalty=1；不再运行官方采样或额外greedy对照。语音生成仍使用各模型原配置。
- 判官Qwen3.8-Omni-Flash，temperature=0，enable_thinking=false，实际听用户与助手音频；明确区分语义失败、模型执行失败和基础设施错误。
- 用户台词由DeepSeek官方API生成，使用qwen-audio-3.1-tts-next合成；所有系统共用数字/单位朗读规范化。
- 开发集验证客观规则、语音证据、评分结构和并发效率；成绩达到50–60%不是验收条件。通过技术验收后推进正式1000题。
- 试听页展示具体中断原因、已执行/被拦截调用、未朗读文本和实际音频，并支持查看旧版记录。
- 交付新版Excel、说明HTML、Markdown、完整可追溯结果和GitHub发布；说明新旧协议差异。

用户最终确认：先验证100题；两条Qwen对照组改greedy。

后续确认：采用修复后的统一机器评分标准运行正式1000题，不再等待人工校准。固定评分流程和原始判断的保留方式见 [全量评分协议](../versions/v0.4/docs/FULL_RUN_POLICY.md)；这不构成人工校准或判官准确率验证。
