# 来源与限制

## 来源

- 对话脚本：DeepSeek 生成，按场景/话题配额筛选；事实、约束、探针为脚本字段。
- 输入语音：qwen3-tts-flash 合成，24kHz。
- 被测系统：edge_native（EdgeInstant-Omni-2B 原生）、qwen35_4b、qwen35_2b、minicpm5_2b（级联 ASR + LLM + TTS）、qwen25_omni_3b（原生）。
- 判官：qwen3.8-omni-flash，阿里云 MaaS 接口，听音频打分。
- 评测框架：本地 HomeVoiceBench-ZH v0.5 + mt-eval 多轮扩展。

## 限制

- 机器生成 + 机器判官，不等同于人工审核；判官分数整体偏高。
- 每场景 100 段抽样，单轮均值置信区间较宽；0.2–0.3 的变化接近噪声。
- qwen35_2b 的 TTS 中途停止，覆盖约 65%；minicpm 已补齐音频。
- 判官逐轮独立打分，不评估整段对话的任务成功率。

## 为什么多轮差异小 / 甚至上升

1. **天花板效应**：0–5 分量表上大量答案落在 4.5–5.0，维度差异被压缩；总分对“是否记得住”不敏感。
2. **逐轮独立评分**：判官看的是单轮音频与提示，不强制做跨轮状态校验；只要回答自然、不矛盾，就能拿高分。
3. **对话设计**：多数轮次的问题可由当前上下文自洽回答，真正的跨轮记忆题占比不高；儿童故事更看重连贯与安全，不要求精确复述。
4. **判官偏差**：后期轮次上下文更长，判官可能因信息更充分而给更高分；不同轮次的评分标准未做严格校准。
5. **样本与噪声**：100 段/场景、单轮均值，0.2 左右的波动在噪声范围内；“反而上升”更可能是判官漂移而非真实提升。
6. **任务口径**：多轮能力应看任务成功率/状态一致性（工具是否正确执行、是否记住约束），而不是单轮自然度均分。
