# 场景目录与配额

## 家居（home）

混合闲聊、便签、提醒与查询。工具为 `add_note`、`set_reminder`、`query_items`。

| 话题 | 说明 |
|---|---|
| 做饭饮食 | 菜谱步骤、食材清单、腌制冷藏 |
| 家居设备 | 空调、加湿器、滤芯、设置 |
| 出行安排 | 出门清单、时间、路线 |
| 家庭健康 | 用药、作息、运动 |
| 收纳整理 | 物品位置、清单 |
| 家务清洁 | 清洁计划、频次 |
| 家庭财务 | 缴费、预算、账单 |

轮次设计覆盖：distract（插入干扰）、change（改条件）、resume（恢复旧话题）、tool（工具调用）、pure_chat（纯闲聊）。

## 儿童（child）

面向 7–10 岁儿童聊天，长故事、角色、情节、约束。年龄段分 7–8 岁与 8–10 岁。

| 话题 | 说明 |
|---|---|
| 睡前故事 | 连续情节、角色关系 |
| 动物朋友 | 拟人故事、对话 |
| 校园生活 | 同学、老师、活动 |
| 情绪安抚 | 害怕、生气、失落 |
| 好奇心问答 | 为什么、怎么 |
| 游戏想象 | 角色扮演、规则 |
| 家庭日常 | 父母、宠物、家务 |
| 节日生日 | 习俗、礼物 |
| 安全常识 | 用电、陌生人、求助 |

## 配额

两个场景各 1,000 段，评测各取前 100 段；案例清单见 `review/data.json` 与 Excel `案例` 页。
