# 数字与单位朗读转换

输入语音由 TTS 朗读，需先把书面数字/单位转成自然口语，否则会出现“一点五”“3.5 度”等不自然读法。

## 规则

- 时间：`14:30` → “下午两点半”；`7:05` → “早上七点零五分”。
- 温度：`26℃` → “二十六度”；`-3℃` → “零下三度”。
- 数量：`1.5 升` → “一点五升”；`500ml` → “五百毫升”。
- 金额：`¥38.5` → “三十八块五”。
- 日期：`12月3日` → “十二月三号”。
- 百分比：`85%` → “百分之八十五”。
- 小数/分数：`0.5` → “零点五”；`1/2` → “二分之一”。

## 实现

`mt-eval/scripts/` 中的 normalize 步骤在 TTS 前处理 `user_text`；判官听的是合成后的音频，故转写错误会直接影响分数。详细规则与用例在 `docs/` 与代码注释中。
