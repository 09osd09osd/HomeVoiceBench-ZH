03 / 场景浏览器

从场景，看到一道具体的题。

选择一个场景，再点选题号查看用户话语。下方文字是审核用原稿；真实测评投递相应语音。

04 / 工具沙箱

16 个工具，共用一套家庭规则。

每道题、每个系统都从相同的初始状态开始。工具有明确参数、权限、错误码和状态变化；不会连接真实家庭设备。

包含离线、暂时失败、超时、延迟执行及取消场景。聊天题也提供相同工具，检测不该执行时有没有误操作。

05 / 评分规则

“说得好”与“做对了”，都有依据。

每类六个维度，按 0–5 分评价。严格通过率另由规则决定；没有运行或没有可评分音频时保留缺失状态。

06 / 完整示例

听输入、看操作、听回答。

两个示例在正式测评前固定选定，用于说明结构。可以逐轮比较三个系统的实际回答。

07 / 实际测评

结果来自真实运行记录。

严格通过率在该统计范围全量评判完成后展示。均分仅包含实际听音评分；整题运行失败仍进入严格通过率分母。这里比较完整系统，离线批处理耗时不作为实时交互延迟。

08 / 如何复现

题目、证据、结论，可以逐层核对。

数据集、模型运行和评分分别保存。查看说明文档可找到每个字段、执行入口和环境配置。

读取题目

核对用户节点、初始家庭、预算、参考轨迹与检查项。

运行系统

投递相同 WAV，保留真实历史，逐次执行沙箱工具。

保存证据

记录调用、状态、原始回答、朗读文本及音频哈希。

听音与汇总

温度 0 的判官听实际输出，再结合客观检查汇总。

阅读结果时，请保留这些边界。
  • 这是干净的合成普通话语音，使用四种成人声音描述；没有据此声称能代表真实远场、噪声或所有年龄的说话人。
  • 后续用户话语预先编写，支持有限澄清；不是自由对话的真人用户模拟。
  • 数据经过结构校验、参考轨迹检查和机器听检，尚未进行人工逐题复核。
  • 一次固定种子运行和单个音频判官不能覆盖所有随机性。配对置信区间仅描述场景抽样的不确定性。
